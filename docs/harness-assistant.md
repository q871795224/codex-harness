# Harness 助理

桌面宠物隐藏时，助理从应用右下角打开，显示应用内悬浮对话窗，背景轻微虚化。显示桌宠后，单击角色打开可独立移动和缩放的原生助理窗口，应用内入口收起。两种入口复用同一个助理会话和完整 Composer，支持附件、模型与推理强度、上下文用量、发送快捷键、延迟发送、插话和排队。助理会话默认使用 YOLO，模型选择只应用于助理会话。收起窗口后，执行和已登记的延迟发送继续运行。

第一版支持按名称、工作区、时间范围或 Provider 查询目录，也可以查看已置顶或已归档的会话。查询范围覆盖 Codex、Claude 和 Superbot 的已保存会话。部分目录不可用时，窗口仍展示可查询来源的结果并标出缺失来源。

自然语言请求由 Codex 在应用管理的专用目录中解析。助理使用可恢复的专用 Codex 会话，Harness 的普通、归档与搜索列表均隐藏该会话。模型接收用户输入、附件及已展示结果的引用，返回筛选条件及操作意图。Harness 查询目录并展示对应会话，用户确认目标后可归档、置顶或取消置顶。归档前检查运行状态和未发送草稿。已归档会话可通过现有历史入口恢复。

## 后续方向

- 设置定位和修改。覆盖全局、插件以及 tab 内设置，跳到具体控件并高亮，复用现有设置更新路径。
- 定期整理。根据最近活动和等待状态，整理继续、等待和建议归档的会话，再由用户确认处理。
- 使用反馈。记录用户主动提出的使用卡点和页面出处，定期汇总重复问题和改进项。
- SeaTalk 跟进。从用户指定的消息分支或聊天范围提取候选待办，保留来源链接并持续更新进度。

桌宠与大肥鱼的使用方式见 [桌面宠物](desktop-pet.md)，窗口和跨窗口服务的开发约定见 [桌宠开发约定](../.harness/desktop-pet.md)。
