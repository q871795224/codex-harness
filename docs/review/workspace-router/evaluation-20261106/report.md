# Router 中英文与输入样式对照实验

实测日期：2026-11-06。主实验已完成 256/256 次请求。正式 Router 与管理页保持现状，语言、格式和后端由用户看结果后决定。

本轮英文分节文本的 Token 最少；纯正文约 571，中文分节文本约 637。完整22工作区时，两种带缩进 JSON 均把用户需求截掉；整段 Prompt 中完整保留需求的 multilingual 文本组最高命中 7/16。Laya 原生短请求另测，multilingual 为 10/16，typed-decisions 为 8/16；历史5条与新增合成11条表现差异见下表。

## 比较对象与口径

测试服务器返回 engine=laya、CPU FP32、eager；固定比较 `laya-multilingual` 和 `laya-typed-decisions`，避免 `jev-latest` 自动别名选择不同 checkpoint。云端 Vercel Jev 本轮未调用；没有发送真实 Codex 模型请求。

四种组合共享同一批候选、用户需求与两条示例：中文/英文 × 带缩进 JSON/Markdown 分节文本。语言切换只翻译指令、介绍和标题，原始中文需求与示例需求保持不变。JSON/文本指 state 内的材料表达，四组 HTTP 外层都使用相同 JSON API。所有组都保留主工作区选择规则，后端用原生 choice 结果，不评价 related 或图片能力。

工作区介绍由本轮根据根目录 AGENTS.md / README 人工整理为等义中英文短介绍，供控制变量实验使用，并非已上线缓存的生成结果。完整组使用当前可见的 22 个工作区加 general；相邻组使用 codex-harness、yf-agent、digital_employee、dns-api、dns-agent、space-sgw-management 加 general。

16 条独立需求包括 5 条沿用首轮记录的人工确认历史文本、11 条事先编写并固定预期的合成案例。两条错误案例（Harness审批卡片排列、Core API端点响应时间）是人工编写的演示数据，所有实验组固定使用，不冒充真实用户反馈；测试需求未原样加入示例。案例固定注入对应“最近优先”的用法，本轮不执行关键词相关筛选。历史原始输入留在本机实验目录，仓库只保留概述、请求哈希与无正文数值结果。

主实验每格 16 条、各调用一次，共 2 个候选规模 × 2 个模型 × 4 种组合 × 16 条 = 256 次。顺序用固定种子随机打散，单并发、30 秒超时、不自动重试，另有每模型一次预热。准确率分别列历史与合成样本；p95 使用 nearest-rank，每格 16 次时取最大值。

## Token 数

以下为 16 条需求在完整 22 工作区组中的平均值，四组信息字段相同。o200k_base 按项目使用的词表本地计数：纯 Prompt 列只含指令和正文；请求文字列还包含 Laya 的固定候选定义。两列均不含 Codex App Server 自动背景、输出 schema 或协议包装，也不作为真实账单。Laya 两列按其实际 tokenizer 与 SDK 序列统计，展示截断前应需数量；模型实际 usage 另见请求结果。

| 语言与样式 | 纯 Prompt o200k_base | 含候选定义 o200k_base | Laya multilingual | Laya typed-decisions |
| --- | ---: | ---: | ---: | ---: |
| 中文 JSON | 1097 | 1307 | 1763 | 1792 |
| 中文分节文本 | 637 | 848 | 833 | 1259 |
| 英文 JSON | 1022 | 1230 | 1744 | 1449 |
| 英文分节文本 | 571 | 780 | 803 | 898 |

仅删除 JSON 缩进和多余空格，中文/英文纯 Prompt 的平均计数为 778 / 724；含候选定义的平均计数分别为 988 / 934。这两项只做本地计数，没有混入 JSON/文本推理效果比较。

纯 Prompt 正文中，中文分节文本约 637，英文约 571，英文节省约 10.4%；当前带缩进 JSON 换成分节文本，中文约节省 41.9%、英文约节省 44.1%。若连 Laya 固定候选定义一起计数，分节文本为 848 / 780，英文节省约 8.0%。这些比例来自本次固定介绍和案例，不代表所有中文或 JSON 都有相同比例。

### 保留中文介绍时的补充计数

2026-11-06 根据用户追问，沿用同一套22工作区、16条需求与两条示例，仅做本地分词，不新增模型调用。当前简介生成代码明确要求输出中文；前述英文实验组的介绍是另外整理的英文版本，尚未接入缓存流程。

| 指令与分区标题 | 工作区介绍 | 平均纯 Prompt o200k_base |
| --- | --- | ---: |
| 中文 | 中文 | 637 |
| 英文 | 中文 | 628 |
| 英文 | 英文 | 571 |

保留中文介绍、仅换英文指令和标题只节省约1.4%；约10.4%的收益需要介绍也采用英文。这里仍是实验模板计数，不作为当前运行中Router的请求测量。AGENTS.md与README可以保持原语言，后台摘要输出语言可以另选；是否改为英文或同次生成双语缓存，仍待用户决定。详见[补充计数](mixed-language-token-counts.json)。

## 完整 22 工作区：截断与选择结果

当前 multilingual 与 typed-decisions 的最大序列均为 1024，候选/指令区另限 256。SDK 会先缩短候选和指令，再从尾部截掉 state；本文采用用户提出的工作区介绍 → 用户输入 → 错误案例顺序。两种带缩进 JSON 下，模型读不到用户需求，表中的命中仅作诊断，不能作为有效路由准确率。

| 模型 | 语言与样式 | 历史命中 | 合成命中 | 合计 | 完整/部分/未读到需求 | 平均秒 / p95秒 |
| --- | --- | ---: | ---: | ---: | --- | ---: |
| multilingual | 中文 JSON | 0/5 | 2/11 | 2/16 | 0/0/16 | 3.04 / 3.20 |
| multilingual | 中文分节文本 | 3/5 | 2/11 | 5/16 | 16/0/0 | 2.41 / 2.83 |
| multilingual | 英文 JSON | 0/5 | 2/11 | 2/16 | 0/0/16 | 3.08 / 3.32 |
| multilingual | 英文分节文本 | 3/5 | 4/11 | 7/16 | 16/0/0 | 2.26 / 2.95 |
| typed-decisions | 中文 JSON | 0/5 | 1/11 | 1/16 | 0/0/16 | 7.16 / 7.31 |
| typed-decisions | 中文分节文本 | 3/5 | 5/11 | 8/16 | 2/14/0 | 7.25 / 8.19 |
| typed-decisions | 英文 JSON | 0/5 | 2/11 | 2/16 | 0/0/16 | 7.22 / 8.07 |
| typed-decisions | 英文分节文本 | 5/5 | 2/11 | 7/16 | 15/1/0 | 6.37 / 7.20 |

typed-decisions 在完整组的中文指令均有截断，英文指令也少量截断；multilingual 的分节文本能完整保留当前样本的指令和 state。英文原始 checkpoint 最大长度只有 512，本地分词显示完整组四种样式均读不到用户需求，因此没有追加它的推理请求。
