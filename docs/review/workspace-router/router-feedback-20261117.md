相关性计算只在检索时忽略“有个、现在、已经、问题、需要”，不改写发给模型的需求和案例。工作区名称和仓库URL中的名称匹配优先；有同项目案例时只引用该组，没有时沿用有效内容词相似度。“最近优先”不受影响，最终工作区仍由模型决定。
