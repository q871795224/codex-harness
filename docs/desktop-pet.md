# 桌面宠物

在 macOS 的「设置 → 桌面宠物」选择已有的 Codex 宠物，或导入自己的素材。宠物显示在其他应用上方。使用下方的拖动柄移动宠物，点击角色打开 Harness 助理，点击铃铛打开最高优先级事项的会话或通知中心。

| 素材 | 导入方式 |
| --- | --- |
| 本机 Codex 宠物 | 刷新列表后直接选择。Harness 只读访问本机 Codex 的 `pets` 目录 |
| Codex 宠物包 | 选择包含 `pet.json` 和清单所指精灵图的目录。支持 v1 的 1536 × 1872 和 v2 的 1536 × 2288 透明 PNG 或 WebP |
| 自己的一组图 | 选中 1–32 张透明 PNG 或 WebP。按文件名排序，放缩居中后作为待机动画播放 |

Codex 图集按其约定播放待机、运行、等待、失败和完成动作，v2 待机时可看向窗口内指针方向。系统开启减少动态效果时显示静帧。散图提供待机循环，仍使用原有通知状态和角标。手动导入的素材保存在 Harness 的宠物目录。

宠物优先提示待回应事项、失败、已关注会话的新结果。要关注当前会话，打开通知中心，在「提醒当前会话」勾选「有新一轮结果时提醒」。点击铃铛打开相关会话，已读状态沿用通知记录，待回应事项由其来源解除。主窗口关闭时会隐藏并继续处理通知。隐藏宠物后可以从设置重新显示。完全退出 Harness 时，宠物及其通知展示一起退出。
