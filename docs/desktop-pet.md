# 桌面宠物

在 macOS 的「设置 → 桌面宠物」选择「大肥鱼 · 内置」，再点「显示桌面宠物」。首次使用会默认选中大肥鱼，已有宠物选择会保留。宠物显示在其他应用上方。长按角色后拖动可移动宠物。单击角色打开独立的 Harness 助理窗口，右击可打开会话、查看通知或隐藏宠物。启用桌宠时，应用内的助理入口收起。

| 素材 | 导入方式 |
| --- | --- |
| 内置大肥鱼 | 随 macOS 应用提供静态预览。可一键下载原画素材，含 89 个随机待机动作。[素材来源与授权](../src-tauri/pets/dafeiyu/NOTICE.md) |
| 本机 Codex 宠物 | 刷新列表后直接选择。Harness 只读访问本机 Codex 的 `pets` 目录 |
| Codex 宠物包 | 选择包含 `pet.json` 和清单所指精灵图的目录。支持 v1 的 1536 × 1872 和 v2 的 1536 × 2288 透明 PNG 或 WebP。宠物包可附带待机随机动作 |
| 自己的一组图 | 选中 1–32 张透明 PNG 或 WebP。按文件名排序，放缩居中后作为待机动画播放 |

Codex 图集按其约定播放待机、运行、等待、失败和完成动作，v2 待机时可看向窗口内指针方向。系统开启减少动态效果时显示静帧。散图提供待机循环，仍使用原有通知状态和角标。手动导入的素材保存在 Harness 的宠物目录。

点击「下载大肥鱼原画」可从上游 GitHub 下载约 139 MiB 的透明视频包。待机呼吸、会话状态和随机动作使用上游的 640 × 360、24 fps 视频，保持原始时长。下载后可离线使用。没有下载素材时，大肥鱼使用静态精灵图。

在「桌面宠物大小」可将桌宠窗口调整为原大小的 20%–400%。点「应用大小」后立即生效。

内置大肥鱼使用预先测定的固定窗口：100% 大小时，静态图为 72 × 90，原画视频为 48 × 54 个逻辑像素。裁掉外圈透明留白后，原生窗口同步缩小，角标固定在右上角，动画和状态变化不改变窗口或角标位置；可拖到桌面可用区域顶部。其他宠物保留原有布局。

大肥鱼原画在可见时连续轮播：先播放一段待机，再随机播放一个动作；动作结束后，从呼吸、打哈欠、哼歌、发呆中随机选一段待机衔接，随后播放下一个随机动作。每段保持原始时长，完整播完再切换，前后两轮尽量不重复动作或衔接待机。下一段加载时保留上一段末帧。会话状态变化时立即播放一遍对应状态动作，随后恢复待机与随机动作轮播；会话持续运行或存在待处理事项不会锁住轮播，通知角标继续反映实际状态。

其他带随机动作的宠物仍在空闲满 60 秒后播放一个动作，有会话状态变化时立即切换到对应状态。隐藏宠物或开启系统的减少动态效果会暂停随机播放。

制作带随机动作的包时，在 `pet.json` 里加入 `"idleAnimations": [{ "path": "idle/dance.webp", "durationMs": 8000 }]`。路径相对于宠物包目录，动画使用单次播放的透明 WebP，`durationMs` 填实际播放时长。每包最多 128 个动作，每个动作最多 4 MiB、宽高均不超过 1024 像素，动作总大小最多 128 MiB。

宠物优先提示待回应事项、失败、已关注会话的新结果。要关注当前会话，打开通知中心，在「提醒当前会话」勾选「有新一轮结果时提醒」。从右键菜单选择「查看通知」打开相关会话，已读状态沿用通知记录，待回应事项由其来源解除。主窗口关闭时会隐藏并继续处理通知。隐藏宠物后可以从设置重新显示。完全退出 Harness 时，宠物及其通知展示一起退出。
